# Dice tool (`ek.dice`)

Built-in EasyKeeper tool for rolling polyhedral dice.

## Third-party

3D dice rendering uses a vendored copy of [@3d-dice/dice-box-threejs](https://github.com/3d-dice/dice-box-threejs) (MIT), including its bundled textures and sound assets under `frontend/vendor/dice-box-threejs/`. See that directory’s `LICENSE` and `ORIGIN.md`.

Thanks to the 3D Dice / Frank Ali project and the Teall / MajorVictory lineage it builds on.
